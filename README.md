# 2026 원화중 3-3 메뉴 조사

학생이 학번·이름을 입력하고 **치킨파 / 엽떡파**를 고른 뒤 순서대로 메뉴를 선택하면, 응답이 선생님 구글 시트에 저장됩니다.

- 치킨파: 브랜드(멕시카나·BHC·BBQ·굽네·호식이) → 메뉴(후라이드·양념·간장·기타, 중복 가능) → 뼈/순살 → 음료(콜라·사이다·제로콜라·제로사이다)
- 엽떡파: 메뉴 → 맵기 → 쿨피스 맛 (시트의 음료 칸에 "쿨피스 ○○"로 저장)
- 같은 학번으로 다시 제출하면 **마지막 제출로 덮어씀** ("응답" 시트). 모든 제출 이력은 "기록" 시트에 남습니다.

## 설정 (선생님, 처음 한 번만)

### 1. 구글 시트 + Apps Script
1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만들고 이름을 `3-3 회식 조사`로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 모두 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣은 뒤 저장(💾)합니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 선택 ⚙️ → **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포** → 권한 승인(고급 → 안전하지 않음으로 이동 → 허용) → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

### 2. 웹 앱 URL 넣기
`index.html` 의 `const SCRIPT_URL = "";` 따옴표 안에 위 URL을 붙여 넣습니다.

### 3. GitHub Pages 켜기
저장소 **Settings → Pages → Branch** 에서 코드가 있는 브랜치와 `/ (root)` 를 고르고 Save.
잠시 후 `https://20261111.github.io/wonhwa3-3/` 로 접속됩니다.

## 메뉴 수정
`index.html` 위쪽 `BRANDS`, `CHICKEN_MENU`, `DRINKS`, `YEOP_MENU`, `YEOP_SPICY`, `COOLPIS` 목록을 고치면 됩니다.
